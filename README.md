Beschrijving
------------

Deze repository bevat Citation Style Language (CSL) stijlen zoals deze gebruikt worden binnen het agentschap Onroerend Erfgoed voor de uniforme opmaak van bronverwijzingen en bibliografieën.

Het .csl-bestand kan gebruikt worden in referentiesoftware die het csl-formaat ondersteunt, zoals Zotero.

Description
-----------
This repository contains the Citation Style Language (CSL) style used by the Flanders Heritage Agency (agentschap Onroerend Erfgoed) for the consistent formatting of citations and bibliographies.

The .csl-file can be used with reference management software that supports the CSL format, such as Zotero.
