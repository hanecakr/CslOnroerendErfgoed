Beschrijving
------------

Deze repository bevat de Citation Style Language (CSL)-stijl die gebruikt wordt binnen het agentschap Onroerend Erfgoed voor de uniforme opmaak van bronverwijzingen en bibliografieën.

De stijl bevat de regels voor de weergave van verschillende types publicaties en andere bronnen, zowel in tekstverwijzingen als in de bibliografie. Het CSL-bestand kan geïnstalleerd en gebruikt worden in referentiesoftware die het CSL-formaat ondersteunt, zoals Zotero.

Om de stijl in Zotero te gebruiken, download je OnroerendErfgoed.csl en voeg je het bestand toe via Instellingen → Cite → Styles → +.

Description
-----------
This repository contains the Citation Style Language (CSL) style used by the Flanders Heritage Agency (agentschap Onroerend Erfgoed) for the consistent formatting of citations and bibliographies.

The style defines the formatting of different types of publications and other sources, both for in-text citations and bibliographic references. The CSL file can be installed and used in reference management software that supports the CSL format, such as Zotero.

To use the style in Zotero, download OnroerendErfgoed.csl and add the file via Settings → Cite → Styles → +.
